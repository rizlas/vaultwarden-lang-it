# vaultwarden-lang-it

Italian translation of all email templates from
[dani-garcia/vaultwarden](https://github.com/dani-garcia/vaultwarden/tree/main/src/static/templates/email)
as described
[here](https://github.com/dani-garcia/vaultwarden/wiki/Translating-the-email-templates).
Admin and 404 templates are also provided.

:warning: Tested for `v1.35.3`
